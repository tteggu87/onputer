# 미결정 사항과 검증 질문

이 문서는 [[source-2026-09-06-product-proposals|제안 원문]]에서 드러난 미결정 사항과 기능별 제한을 모았다. 아래 질문을 해결하기 전에는 제안을 확정 요구사항이나 검증된 효과로 바꾸지 않는다.

## 확정된 문서화 범위

사용자는 제품 제안을 위키로 남기고 Markdown만 사용하도록 요청했다. 이에 따라 이 위키는 Markdown이 기준이며 SQLite는 사용하지 않는다. 이 요청은 후보 기능 전체의 구현 승인과 다르다.

## 아직 결정되지 않은 항목

| 항목 | 현재 상태 | 결정에 필요한 확인 |
|---|---|---|
| 첫 연결 대상 웹 서비스 | 미정 | 인증·터널·실제 도구 호출과 결과 표시를 해당 서비스에서 확인 |
| 대표 실무 작업 | 미정 | 어떤 반복 업무로 제품 가치를 검증할지 선택 |
| 첫 출시 범위 | 제안 두 가지 존재 | 단계별 순차 진행과 관리 화면·이력·결과의 통합 묶음 중 범위 결정 |
| 기록·복원의 범위 | 경계만 제안됨 | 보관할 기록과 복원 가능한 파일 변경 범위 구체화; 외부 효과는 구분 |
| 선택 확장의 범위 | 브라우저·문서·이미지가 후보 | 기본 설치에 포함할지 선택 확장으로 둘지 실제 수요 확인 |
| 일정·비용·측정 기준 | 미산정·미확정 | 범위 결정 후 필요한 노력과 완료 판단을 구체화 |

## 결과를 해석할 때의 주의점

- 기존 서버 기능의 CI 통과와 새로운 사용자 경험의 효과 검증은 별개다.
- 체크포인트는 이미 푸시하거나 외부 서비스에 요청한 효과 전체를 되돌리는 약속이 아니다.
- 작업 재개는 종료된 프로세스의 무조건 재실행이 아니다.
- MCP의 이미지·리소스 링크 지원과 웹 서비스의 실제 UI 지원은 별개다.
- 읽기 전용은 실제로 쓰기와 명령을 막아야 하며, 실행 허용을 작업공간 격리라고 설명하지 않는다.
- 결과 화면 예시의 파일·테스트 수는 성과 수치가 아니다.
